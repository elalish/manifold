void SetRelativePrecision ( double p)
static

Sets the relative precision for geometric computations, defining what counts as coplanar or degenerate, and therefore how much simplification can occur.

Parameters
pThe relative precision value. The default is 1e-12 for double precision, and smaller values will be clamped to this minimum.
