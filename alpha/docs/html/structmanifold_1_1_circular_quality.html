Detailed Description

Controls how circular shapes are quantized on construction. Pass one to CrossSection::Circle(), CrossSection::Offset(), Manifold::Cylinder(), Manifold::Sphere(), and Manifold::Revolve().

If segments is greater than two (for a Sphere, positive), it takes precedence. Otherwise the minimum is used of the segments calculated based on edge length and angle, rounded up to the nearest multiple of four. To get numbers not divisible by four, segments must be specified.

◆ ForDivisions()

CircularQuality ForDivisions ( int divisions,
double degrees )
static

Returns a quality that makes Manifold::Revolve() divide the given angle into exactly this many divisions. Like Revolve, it uses the angle's magnitude, clamped to 360 degrees. A revolve of more than 120 degrees needs at least two divisions, and of more than 240 degrees at least three, and a tiny angle cannot get more divisions than the largest int count allows. Past those limits it returns the closest count Revolve allows. A non-finite or zero angle, which Revolve rejects, gives the default quality.

Parameters
divisionsNumber of divisions. Values below 1 are treated as 1.
degreesAngle Revolve will sweep.

Member Data Documentation

◆ segments

int segments = 0

Number of segments in a full 360-degree circle. Pass {n} to set just this. Partial revolves use the matching fraction of it, rounded up, ignoring an excess of one unit in the last place so floating-point error cannot add a division (see ForDivisions()). A Sphere rounds it up to a multiple of four. Values below 3 apply no constraint, except that Sphere takes any positive count.
