cross_section__warp__warp_func:
  Move the vertices of this CrossSection (creating a new one) according to
  any arbitrary input function, followed by a union operation (with a
  Positive fill rule) that ensures any introduced intersections are not
  included in the result.
  :param warp_func: A function that takes the original vertex position and
  return the new position.
cross_section__warp_batch__warp_func:
  Same as CrossSection::warp but calls warpFunc with
  an ndarray[n, 2] instead of processing only one vertex at a time.
  :param warp_func: A function that takes multiple vertex positions as an
  ndarray[n, 2] and returns the new vertex positions. The result should have the
  same shape as the input.
manifold__warp__warp_func:
  This function does not change the topology, but allows the vertices to be
  moved according to any arbitrary input function. It is easy to create a
  function that warps a geometrically valid object into one which overlaps, but
  that is not checked here, so it is up to the user to choose their function
  with discretion.
  :param warp_func: A function that takes the original vertex position and
  return the new position.
manifold__warp_batch__warp_func:
  Same as Manifold::warp but calls warpFunc with
  an ndarray[n, 3] instead of processing only one vertex at a time.
  :param warp_func: A function that takes multiple vertex positions as an
  ndarray[n, 3] and returns the new vertex positions. The result should have the
  same shape as the input.
manifold__set_properties__num_prop__prop_func:
  Create a new copy of this manifold with updated vertex properties by
  supplying a function that takes the existing position and properties as
  input. You may specify any number of output properties, allowing creation and
  removal of channels.
  Any normals recording set by calculate_normals() is preserved if
  num_prop is at least 3, and dropped otherwise. If the new properties
  overwrite slot 0..2 with non-normal data, the recording becomes stale. Call
  calculate_normals() again to reset.
  :param num_prop: The new number of properties per vertex.
  :param prop_func: A function that takes the vertex position and an ndarray
  of its old properties, and returns its new properties as an array or list of
  length num_prop. Any other length raises an error.
manifold__level_set__sdf__bounds__edge_length__level__tolerance__can_parallel:
  Constructs a level-set manifold from the input Signed-Distance Function
  (SDF). This uses a form of Marching Tetrahedra (akin to Marching
  Cubes, but better for manifoldness). Instead of using a cubic grid, it uses a
  body-centered cubic grid (two shifted cubic grids). These grid points are
  snapped to the surface where possible to keep short edges from forming.
  Invalid bounds or edge_length raise ManifoldError with code
  InvalidConstruction.
  :param sdf: The signed-distance function sdf(x, y, z), which returns the
  signed distance of a given point in R^3. Positive values are inside,
  negative outside. There is no requirement that the function be a true
  distance, or even continuous.
  :param bounds: The extent of the grid as (xmin, ymin, zmin, xmax, ymax,
  zmax), the same format as bounding_box().
  :param edge_length: Approximate maximum edge length of the triangles in the
  final result. Must be positive and finite. This affects grid spacing, and
  hence has a strong effect on performance. Every positive-length axis has at
  least one grid interval, including when its extent is smaller than
  edge_length.
  :param level: Extract the surface at this value of your sdf; defaults to
  zero. You can inset your mesh by using a positive value, or outset it with a
  negative value.
  :param tolerance: Ensure each vertex is within this distance of the true
  surface. Defaults to -1, which will return the interpolated
  crossing-point based on the two nearest grid points. Small positive values
  will require more sdf evaluations per output vertex.
manifold__status:
  Returns the error status of this Manifold without raising. Calls that
  evaluate a Manifold with an error raise ManifoldError instead, so this is
  the way to check a lazy result, such as a Boolean or a transform. An error
  carries on through lazy operations like NaN propagation, so it doesn't get
  mysteriously lost. Every error leaves an empty Manifold. Empty Manifolds
  may still show NoError: empty input gives empty output with no error, as
  does the intersection of non-overlapping meshes.
manifold__is_empty:
  Does the Manifold have any triangles? Raises ManifoldError for a Manifold
  with an error status, since it is invalid rather than empty.
