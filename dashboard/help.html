Manifold benchmark dashboard help

What data is in the dashboard?

The dashboard reads weekly benchmark JSON files from the benchmark-data branch. The default source is https://raw.githubusercontent.com/elalish/manifold/benchmark-data. For local testing against a fork, append ?data=<raw benchmark-data branch URL> to any dashboard page URL. Release-triggered benchmark runs are stored in the same timeline and marked with their release tag.

Pages

graphs shows Highcharts line charts for weekly benchmark trends.

latest shows metadata for the latest loaded run.

runs lists loaded historical runs and links to raw JSON.

Measured suites

  • perfTest size sweep time and peak RSS.
  • Selected Ember phase timings.
  • Selected existing gtests.
  • Sanitizer subset summary status from the weekly workflow.
  • Release tags, when a run was triggered by a published release.
