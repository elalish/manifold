Manifold weekly benchmarks

What data is in the dashboard?

The dashboard reads weekly benchmark JSON files from the benchmark-data branch. It shows the perfTest size sweep, selected Ember phase timings, and selected existing gtests. The charts use Highcharts line graphs, matching the approach used by the rustc-perf dashboard.
