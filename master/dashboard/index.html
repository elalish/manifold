Manifold benchmark dashboard help


    

      What data is in the dashboard?
      

        The dashboard reads weekly benchmark JSON files from the benchmark-data
        branch. The default source is https://raw.githubusercontent.com/elalish/manifold/benchmark-data.
        For local testing against a fork, append ?data=<raw benchmark-data branch URL>
        to the dashboard URL. The URL must point at the branch root (e.g.
        https://raw.githubusercontent.com/<you>/manifold/benchmark-data),
        not the weekly/ subdirectory.
        Release-triggered benchmark runs are stored in the same timeline and marked
        with their release tag.
